MY FINANCE V3.1
================
ไฟล์หลัก: index.html, style.css, script.js, manifest.json, sw.js และไอคอน

ระบบที่รวมอยู่
- Dashboard รายรับ รายจ่าย กราฟ และกรองเดือน
- เพิ่ม/แก้ไข/ลบรายการรายรับรายจ่าย และหมวดหมู่
- ระบบหนี้ ผ่อนชำระ บัตรเครดิต และบันทึกการชำระรายเดือน
- สำรอง/กู้คืนข้อมูลรายการ หมวดหมู่ และหนี้เป็น JSON
- PWA / Service Worker สำหรับแคชไฟล์หลัก
- สแกนสลิปหลายภาพหรือถ่ายจากกล้อง
- OCR ภาษาไทยและอังกฤษผ่าน Tesseract.js ที่ทำงานในเบราว์เซอร์
- หน้าตรวจสอบข้อมูลทั้งหมดก่อนบันทึกเป็นรายจ่าย
- ตรวจเลขอ้างอิงซ้ำและรายการที่ยอด/วันที่คล้ายกัน
- เก็บภาพสลิปแยกใน IndexedDB, เปิดดูภาพ, กรองวันที่ และลบรูปโดยเก็บรายการไว้

ติดตั้ง/อัปเดต
1. ก่อนแทนเว็บเดิม ให้เปิดเว็บเดิมแล้วไปที่ ตั้งค่า > สำรองข้อมูล เพื่อดาวน์โหลดไฟล์ JSON
2. แตก ZIP แล้วอัปโหลดไฟล์ทั้งหมดภายในโฟลเดอร์ my-finance-v3.1 ไปยัง Netlify หรือ GitHub Pages โดยคงชื่อไฟล์และโครงสร้างไว้
3. เปิดเว็บผ่าน HTTPS แล้วทดสอบรายการเดิมก่อนใช้งานจริง
4. บน iPhone เปิดด้วย Safari > Share > Add to Home Screen
5. หากเว็บเก่าค้างอยู่ ให้ปิดแอป/แท็บแล้วเปิดใหม่เพื่อรับ Service Worker เวอร์ชันใหม่

ข้อจำกัดสำคัญ
- รายการเดิมยังใช้ localStorage keys myFinanceTransactions และ myFinanceCategories; หนี้ใช้ myFinanceDebts
- รูปสลิปเก็บใน IndexedDB แยกจากรายการ และยังไม่รวมในไฟล์ JSON สำรอง จึงไม่ย้ายรูปสลิปไปเครื่องใหม่ผ่านไฟล์สำรองนี้
- OCR ประมวลผลภาพในเบราว์เซอร์และไม่ได้ส่งภาพไปยัง API OCR แต่ครั้งแรกต้องใช้อินเทอร์เน็ตโหลดไลบรารีและข้อมูลภาษา (CDN); OCR อาจอ่านผิด ต้องตรวจข้อมูลก่อนบันทึก
- OCR อาจต้องใช้ RAM/พื้นที่มากเมื่อเลือกภาพจำนวนมาก ควรเริ่มทีละชุดเล็ก ๆ
- ฟีเจอร์ OCR ออฟไลน์ครั้งแรกยังไม่รับประกัน เพราะไฟล์ OCR/ข้อมูลภาษาไม่ได้ถูก bundle ไว้ใน ZIP
- ตรวจรายการซ้ำเป็นการแจ้งเตือนเชิงประมาณ ไม่รับประกันว่าจะจับได้ทุกกรณี และผู้ใช้สามารถยืนยันบันทึกต่อได้
- ระบบหนี้ไม่ได้เชื่อมกับธนาคารหรือผู้ให้บริการบัตรเครดิต ต้องกรอกและตรวจยอดเอง
- ข้อมูลไม่ซิงก์ข้ามอุปกรณ์อัตโนมัติ ควรสำรอง JSON เป็นประจำ
- ทดสอบ JavaScript syntax แล้ว แต่ยังต้องทดสอบบน iPhone จริงกับสลิปจากธนาคารที่ใช้งานก่อนพึ่งพาในชีวิตประจำวัน
